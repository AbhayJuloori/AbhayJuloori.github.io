# abhayjuloori.github.io

Personal portfolio of Abhay Juloori, applied data scientist. Next.js static export, deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm ci
npm run dev        # http://localhost:3000
npm run build      # validates freight evidence, then exports to out/
```

Project content lives in `lib/` (`projects.ts`, `case-studies.ts`, `experience.ts`, `working-on.ts`, `games.ts`). Every number on a case-study page traces to the source repository's README or results files.
